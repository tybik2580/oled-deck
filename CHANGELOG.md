# Изменения агента OLED Deck

Файлы каждой версии — в [Releases](../../releases): `OLEDDeckAgent.exe` и `SHA256SUMS.txt`.

## v1.0.0

Первый публичный выпуск.

- Пульт для телефона в локальной сети: системные показатели, плеер, микшер, кнопки, OBS, обои Wallpaper Engine.
- Вход по 6-значному PIN-коду, отдельный ключ для каждого телефона, отключение отдельного телефона на странице `/connect`.
- Агент принимает только раскладки, подписанные сайтом для этого ПК.
- Защита от DNS rebinding и запросов с чужих сайтов.
- Громкость с телефона меняет только плеер — не общую громкость Windows и не игры.
- Новый запуск `.exe` сам заменяет работающую копию и обновляет путь автозапуска.
