# Безопасность OLED Deck

Здесь честно описано, что делает агент на вашем ПК, какие данные он видит и куда они идут, как защищён доступ и какие ограничения у этой защиты есть. Описание соответствует последней версии в [Releases](../../releases/latest).

## Коротко

- Пульт работает **только в вашей локальной сети**: телефон соединяется с ПК напрямую, без наших серверов посередине.
- **Агент не отправляет нам никаких данных**: ни телеметрии, ни статистики, ни отчётов об ошибках. Своих серверов он вообще не вызывает.
- Вход с телефона — по **6-значному PIN-коду**. Каждый телефон получает собственный ключ, и его можно отключить отдельно.
- Агент выполняет **только действия из белого списка**, а кнопки берёт только из раскладки, **подписанной сайтом** для вашего ПК.

## Какие данные использует агент и куда они идут

Агент собирает данные на ПК и отдаёт их **только телефонам, вошедшим по PIN**, внутри вашей сети:

| Данные | Откуда | Кому |
|---|---|---|
| загрузка CPU, ОЗУ, GPU (через `nvidia-smi`), сеть, батарея, характеристики ПК | Windows | телефону |
| что сейчас играет: название, исполнитель, обложка; имя плеера и сайта (YouTube, Spotify…) | медиасессия Windows, заголовок окна плеера | телефону |
| список приложений со звуком и их громкость, устройства вывода | микшер Windows | телефону |
| превью обоев Wallpaper Engine | файлы Wallpaper Engine; кадр снимается **только с окна обоев**, не с экрана | телефону |
| расход Claude Code | локальные логи `~/.claude`, **только если такой виджет есть в раскладке** | телефону |

Агент сам выходит в интернет только для двух виджетов и только если они есть в раскладке:

- **«Пинг»** — TCP-соединение с `store.steampowered.com`, `www.faceit.com`, `www.riotgames.com`, данные не передаются;
- **«Курсы»** — открытые API `open.er-api.com` и `api.coingecko.com`.

**Журнал** `%APPDATA%\OLED Deck\agent.log` хранится только на вашем ПК. В нём есть IP-адреса телефонов и адреса запросов, но не PIN и не ключи сессий.

## Что не собирается

- Никакой телеметрии, аналитики или отчётов об ошибках из агента.
- Нет записи нажатий клавиш, буфера обмена, содержимого экрана и файлов. Снимок для фона берётся только с окна Wallpaper Engine.
- Агент не загружает ваши файлы ни на сайт, ни куда-либо ещё.
- PIN-код не передаётся на сайт и в базу данных: браузер отдаёт его прямо агенту на этом же ПК, а тот хранит только хеш.

## Как защищён доступ

**PIN-код**
- 6 цифр; простые коды (`111111`, `123456`, `987654` и подобные) отклоняются.
- Хранится только как солёный хеш **scrypt** в `%APPDATA%\OLED Deck\pairing.json`.
- Защита от перебора: каждые 5 неверных попыток блокируют вход на 30 с, затем 1, 2, 4 минуты… до часа. Один IP-адрес после 10 ошибок блокируется на минуту.
- Сменить PIN можно только зная текущий. Если вы его забыли: трей → «Выход», удалите `pairing.json`, запустите агент и задайте новый PIN.

**Сессии телефонов**
- После верного PIN телефон получает собственный случайный ключ (256 бит). Агент хранит только его SHA-256, поэтому по файлу войти нельзя.
- Ключ, которым не пользовались 90 дней, перестаёт работать.
- Отключить отдельный телефон: `http://localhost:3838/connect` → «Телефоны с доступом» → «Отключить». Отключить все: на сайте «Выйти на всех телефонах» или смените PIN.

**Защита от атак через браузер**
- Агент отвечает только на свои адреса: `localhost`, `127.0.0.1` и текущие IP вашего ПК. Это закрывает DNS rebinding: чужой сайт не может притвориться локальным адресом.
- Действия и WebSocket принимаются только со страниц самого агента. Сайт OLED Deck допущен к нескольким служебным вызовам по CORS, и только с этого же ПК.
- Страницы `/connect` и `/logs` (QR-код, список телефонов, журнал) открываются только с самого ПК.

**Что может делать кнопка**
Раскладку агент принимает **только подписанной сайтом (Ed25519)**, для этого конкретного ПК и только что. Правка файлов на диске или подложенная раскладка не сработают. Перед выполнением каждая кнопка ещё раз сверяется с белым списком:

- горячие клавиши из списка допустимых клавиш;
- ввод заданного вами текста;
- открытие ссылок `http(s)`, `steam://`, Epic, Battle.net, Ubisoft, EA, Discord, Spotify;
- запуск файла `.exe`, `.lnk`, `.bat` или `.url`, путь к которому **вы сами указали** в конструкторе;
- выключение и перезагрузка — **с подтверждением** на телефоне; сон, блокировка, выключение микрофона, режим питания;
- команды OBS через локальный obs-websocket (`127.0.0.1:4455`);
- воспроизведение указанного вами звукового файла.

Других команд (произвольной командной строки, доступа к файлам) у агента нет. Громкость с телефона меняет **только плеер**, но не общую громкость Windows и не игры.

## Сайт и аккаунт

- Вход по email и паролю через Supabase Auth (пароль хранит Supabase в виде хеша).
- В аккаунте хранятся раскладки, пресеты и загруженные вами картинки и видео для виджетов. **Загруженные медиафайлы доступны по прямой ссылке** — не загружайте личное.
- Оплата идёт через Stripe: данные карты мы не видим и не храним.

## Известные ограничения

- **Связь телефон ↔ ПК идёт по обычному HTTP без шифрования.** В чужой или общественной сети PIN и ключ сессии можно перехватить, поэтому используйте пульт **только в своей домашней сети**. Брандмауэр стоит разрешать только для частных сетей.
- **Ключ сессии хранится в адресе пульта**: так иконка «На экран Домой» на iPhone открывается без повторного ввода PIN. Не публикуйте скриншоты адресной строки. Если ключ утёк — отключите этот телефон на `/connect`.
- **Сам ПК считается доверенным**: программы на нём обращаются к агенту без PIN. Если на ПК уже есть вредоносная программа, агент от неё не защитит.
- **Файл пока без цифровой подписи кода** (отсюда предупреждение SmartScreen). Подлинность проверяйте по `SHA256SUMS.txt` из релиза.
- Устройство в той же сети может перебором неверных PIN **временно заблокировать вход** для новых телефонов (уже вошедшие продолжают работать).

## Проверка подлинности файла

В каждом релизе рядом с `OLEDDeckAgent.exe` лежит `SHA256SUMS.txt`:

```powershell
Get-FileHash .\OLEDDeckAgent.exe -Algorithm SHA256   # сравните с SHA256SUMS.txt
```

Скачивайте агент только из Releases этого репозитория. Файл с тем же именем из другого места не используйте.

## Поддерживаемые версии

Исправления безопасности выходят только для **последней** версии агента. Обновляйтесь: скачайте новый релиз и запустите его — он сам заменит работающую копию и обновит путь автозапуска.

## Сообщить об уязвимости

**Не создавайте публичный Issue.** Сообщите приватно: вкладка **Security** этого репозитория → **Report a vulnerability**. Опишите, что затронуто, шаги воспроизведения и версию агента.

- Подтвердим получение в течение **7 дней** и будем держать вас в курсе исправления.
- После выхода исправленной версии, с вашего согласия, упомянем вас в релизе.
- Добросовестное исследование своей копии агента в своей сети мы приветствуем. Не атакуйте чужие устройства и аккаунты других пользователей.
