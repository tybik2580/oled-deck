# OLED Deck

**Пульт для ПК на экране телефона.** Телефон в той же Wi-Fi сети показывает загрузку CPU/GPU/ОЗУ, сеть, что сейчас играет, и кнопки, которые вы сами настроили: горячие клавиши, запуск игр и программ, OBS, громкость плеера. Раскладка собирается в конструкторе на сайте, а работает напрямую между ПК и телефоном — без облака посередине.

*English: OLED Deck turns a phone on your home Wi-Fi into a control deck for your Windows PC. A small agent on the PC serves the remote over the local network; the phone signs in with a 6-digit PIN. See [SECURITY.md](SECURITY.md) for the security model.*

## Как это работает

```
 ┌────────────── ваш ПК (Windows) ──────────────┐          ┌──── телефон ────┐
 │  OLED Deck Agent  ── http://<IP ПК>:3838 ────┼── Wi-Fi ─┤  браузер / иконка│
 │  (трей, порт 3838, данные в %APPDATA%)       │  (LAN)   │  «На экран Домой»│
 │        ▲                                     │          └─────────────────┘
 │        │ раскладка, подписанная сайтом       │
 │  браузер с конструктором (сайт OLED Deck)    │
 └──────────────────────────────────────────────┘
```

1. **Агент** — один файл `OLEDDeckAgent.exe`, установка не нужна. Работает в трее, слушает порт **3838** в локальной сети, при первом запуске добавляет себя в автозапуск Windows (отключается в меню трея).
2. **Конструктор** на сайте: вы собираете раскладку виджетов и кнопок, сохраняете её в аккаунте. Сайт подписывает сохранённую раскладку и через ваш же браузер передаёт её агенту на этом ПК.
3. **Телефон** открывает адрес ПК (QR-код на странице `http://localhost:3838/connect`), вы вводите **6-значный PIN**, и пульт работает напрямую с ПК по Wi-Fi.

## Безопасный запуск

1. **Скачивайте агент только из [Releases](../../releases/latest) этого репозитория** (или по кнопке на сайте, которая ведёт сюда же).
2. **Сверьте контрольную сумму** — она должна совпасть с `SHA256SUMS.txt` из того же релиза:
   ```powershell
   Get-FileHash .\OLEDDeckAgent.exe -Algorithm SHA256
   ```
   или `certutil -hashfile OLEDDeckAgent.exe SHA256`. Не совпадает хоть один символ — не запускайте файл.
3. **SmartScreen.** Файл пока без цифровой подписи кода, поэтому Windows может показать «Система Windows защитила ваш компьютер». Если сумма совпала: «Подробнее» → «Выполнить в любом случае».
4. **Брандмауэр.** При первом запуске разрешите доступ **только для частных сетей**. Общественный Wi-Fi (кафе, общежитие, гостиница) для пульта не подходит — подробнее в [SECURITY.md](SECURITY.md).
5. **PIN-код** задаётся в конструкторе на сайте (аватар → «PIN-код для телефона»). Простые коды вроде `111111` и `123456` не принимаются.
6. **Телефон.** Откройте QR-код (трей → «Открыть панель»), отсканируйте, введите PIN. На iPhone: «Поделиться» → «На экран Домой».

**Как убрать агент полностью:** трей → «Выход», затем удалите `OLEDDeckAgent.exe` и папку `%APPDATA%\OLED Deck`; автозапуск снимается галочкой в меню трея (или удалите параметр `OLED Deck` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`). Агент ничего не устанавливает в систему и не требует прав администратора.
